# 单位根详解

单位根是复数理论里非常重要的一类特殊复数,也是傅里叶变换、多项式插值等算法背后的几何基础。

## 一、什么是单位根

**定义**:方程
$$x^n = 1$$
的所有复数解,叫做 **$n$ 次单位根**(nth roots of unity)。

在实数范围内,$x^n=1$ 通常只有 1 个或 2 个解(比如 $n$ 为奇数时只有 $x=1$;$n$ 为偶数时有 $x=\pm1$)。但在**复数**范围内,这个方程恰好有 **$n$ 个不同的解**——这正是复数域比实数域"更完整"的体现(代数基本定理保证 $n$ 次方程恰有 $n$ 个复根)。

## 二、为什么恰好是 $n$ 个,而且都在单位圆上

**先看模长**:如果 $x^n=1$,两边取模:
$$|x|^n = |1| = 1 \quad\Longrightarrow\quad |x| = 1$$

(因为模长是非负实数,非负实数的 $n$ 次方等于 1,只能是 1 本身)。所以**每一个单位根的模长都是 1**——它们全部落在复平面的**单位圆**上,这也是"单位根"这个名字的由来。

**再看幅角**:设 $x = e^{i\theta}$(模长已经确定是 1),代入方程:
$$x^n = e^{in\theta} = 1$$

要让 $e^{in\theta}=1$,根据欧拉公式,需要 $\cos(n\theta)=1$ 且 $\sin(n\theta)=0$,也就是 $n\theta$ 必须是 $2\pi$ 的整数倍:
$$n\theta = 2\pi k \quad(k\text{ 为整数}) \quad\Longrightarrow\quad \theta = \frac{2\pi k}{n}$$

当 $k=0,1,2,\dots,n-1$ 时,$\theta$ 取遍 $[0,2\pi)$ 内 $n$ 个互不相同的角度(再往后 $k=n$ 时 $\theta=2\pi$,和 $k=0$ 是同一个点,开始循环)。所以恰好有 $n$ 个不同的解。

## 三、统一的表达式

把上面的结论写成通用公式:第 $k$ 个 $n$ 次单位根是
$$x_k = e^{i\cdot 2\pi k/n} = \cos\left(\frac{2\pi k}{n}\right) + i\sin\left(\frac{2\pi k}{n}\right), \qquad k=0,1,2,\dots,n-1$$

**验证一下这确实是根**:
$$x_k^n = \left(e^{i\cdot 2\pi k/n}\right)^n = e^{i\cdot 2\pi k} = \cos(2\pi k)+i\sin(2\pi k) = 1$$

(因为 $k$ 是整数,$2\pi k$ 转了整数圈,又回到角度 0 的位置)。

## 四、生成元 $\omega_n$

在这 $n$ 个根里,有一个特殊的根:
$$\omega_n = e^{i\cdot 2\pi/n}$$

它是幅角**最小的非零**单位根(对应 $k=1$)。之所以特殊,是因为**所有其他单位根,都可以写成它的整数次幂**:
$$x_k = \omega_n^k, \qquad k=0,1,\dots,n-1$$

验证:$\omega_n^k = \left(e^{i\cdot2\pi/n}\right)^k = e^{i\cdot2\pi k/n} = x_k$,正好对上。这就是为什么 $\omega_n$ 被称为**生成元(generator)**——从它出发不断自乘,就能"生成"出全部 $n$ 个单位根。

**几何理解**:把 $\omega_n$ 看成"每次旋转 $2\pi/n$ 弧度"的操作。从 $1$(即 $\omega_n^0$)开始,不断乘以 $\omega_n$,点就在单位圆上一步步跳动:$1\to\omega_n\to\omega_n^2\to\cdots\to\omega_n^{n-1}$,跳满 $n$ 步正好转完一整圈,回到 $\omega_n^n=1$。

### 用"切分单位圆"来理解

把单位圆用 **$n$ 条从原点出发的射线**均匀分成 $n$ 份(不是"切线",切线是只碰圆一点的那种线;这里说的是从圆心发出、把圆周等分的射线),每条射线和圆周的交点,依次是:
$$\omega_n^0,\ \omega_n^1,\ \omega_n^2,\ \dots,\ \omega_n^{n-1}$$

具体来说,**第 $k$ 条射线是从 $x$ 轴正方向逆时针转过 $k$ 份(每份角度 $2\pi/n$)得到的位置**,对应的交点就是 $\omega_n^k$:

- 第 $0$ 条射线就是 $x$ 轴正方向本身,交点是 $\omega_n^0=1$
- 第 $1$ 条射线转过 1 份,交点是 $\omega_n^1=\omega_n$(生成元)
- 第 $k$ 条射线转过 $k$ 份,交点是 $\omega_n^k$
- 第 $n$ 条射线转过 $n$ 份,正好转满一整圈,又回到第 $0$ 条射线的位置(即 $\omega_n^n=1$)

## 五、"转回1"是什么意思

**"1"指的是复数 $1+0i$**,也就是复平面上坐标为 $(1,0)$ 的点——在单位圆上,它正好是角度为 $0°$ 的位置(实轴正方向与圆的交点)。

"转回1"说的是:**当你把 $\omega_n$ 乘了若干次之后,算出来的这个复数,数值上恰好等于 $1$,也就是又落回了那个 $(1,0)$ 的起点位置**。

用一个具体例子($n=4$)看一下:

$$\omega_4 = i \ (\text{角度 } 90°)$$
$$\omega_4^2 = i^2 = -1 \ (\text{角度 } 180°)$$
$$\omega_4^3 = i^3 = -i \ (\text{角度 } 270°)$$
$$\omega_4^4 = i^4 = 1 \ (\text{角度 } 360°=0°)$$

乘到第 4 次的时候,算出来的值又变回了 $1$——这就是"转回1":走了一整圈(360°),又回到了出发点。

**类比理解**:就像时钟的秒针从 12 点出发,走一整圈之后,秒针又重新指向 12 点。"回到 12 点"不是秒针停下来了,而是它转了一整圈之后,位置又和出发时一样了。

之所以用"转"这个动词,是因为单位根的每一次自乘,几何上对应的就是"绕原点旋转一个固定角度"(模长为 1 的复数相乘,只改变角度,不改变到原点的距离)。所以:

> "$\omega_n$ 自乘 $k$ 次" = "对应向量绕原点转了 $k$ 步" = "算出来的复数值等于第 $k$ 个单位根"

三种说法说的是同一件事。

## 六、几条重要性质

**性质 1:$\omega_n^n = 1$(循环性)**

这是最基本的性质。它意味着 $\omega_n$ 的幂是**周期性**的,周期为 $n$:
$$\omega_n^{n+j} = \omega_n^n\cdot\omega_n^j = 1\cdot\omega_n^j = \omega_n^j$$

**性质 2:恒有 $1$ 是单位根**

不管 $n$ 是多少,$k=0$ 时 $x_0=e^0=1$,所以 $1$ 永远是单位根之一。

**性质 3:"频率"概念——$\omega_n^k$ 多快转回 1**

如果 $k$ 能整除 $n$(设 $n=km$),那么 $\omega_n^k$ 只需要转 $m=n/k$ 步就能回到 1:
$$(\omega_n^k)^{m} = \omega_n^{km} = \omega_n^n = 1$$

**具体例子理解($n=12,\ k=3$)**:

$\omega_{12}$ 转一步是 $2\pi/12=30°$。取 $z=\omega_{12}^3$,它对应角度 $3\times30°=90°$,是一个固定的点。现在问:$z,z^2,z^3,\dots$ 要乘几次才能回到 1?

$$z=\omega_{12}^3\ (90°),\quad z^2=\omega_{12}^6\ (180°),\quad z^3=\omega_{12}^9\ (270°),\quad z^4=\omega_{12}^{12}=1\ (360°)$$

只用 4 步就回到 1,对应 $m=n/k=12/3=4$。

**为什么是 $n/k$ 步**:$z$ 每乘一次,角度增加 $k$ 个"最小步长"$2\pi/n$。要转满一整圈,需要走满 $n$ 个最小步长,而 $z$ 每次走 $k$ 个,所以需要的次数就是 $n/k$——本质上是"总路程 ÷ 每步距离 = 步数"这个最朴素的除法关系。

**为什么说它是"$m$ 次单位根",且"转得比 $\omega_n$ 快 $k$ 倍"**:

$z^m=1$ 正好符合"$m$ 次单位根"的定义(满足 $x^m=1$ 的数),所以 $z=\omega_n^k$ 可以被看成一个独立的、$m$ 次单位根系统里的生成元。而对比原来的 $\omega_n$(要 $n$ 步转一圈)和 $z$(只要 $n/k$ 步转一圈),$z$ 用的步数只有原来的 $1/k$,也就是转一圈所花的"时间"缩短为原来的 $1/k$,换句话说转速是原来的 $k$ 倍。这个"多快转一圈"的概念,后面在傅里叶变换里被解释为**频率**。

**性质 4:$n$ 为偶数时,存在一个特殊的"中间根"**

当 $n$ 是偶数,取 $k=n/2$:
$$\omega_n^{n/2} = e^{i\cdot 2\pi/n \cdot n/2} = e^{i\pi} = -1$$

这正是欧拉恒等式的直接体现。这个根的性质很特别:自乘一次变成 $1$,再自乘变回 $-1$……在 $-1$ 和 $1$ 之间来回振荡,"频率"是 $2$(每 2 步循环一次)。

**性质 5:单位根之和为零(当 $n\geq2$ 时)**

$$\sum_{k=0}^{n-1}\omega_n^k = 1+\omega_n+\omega_n^2+\cdots+\omega_n^{n-1} = 0$$

这是等比数列求和公式的直接结果:
$$\sum_{k=0}^{n-1}\omega_n^k = \frac{\omega_n^n-1}{\omega_n-1} = \frac{1-1}{\omega_n-1} = 0 \quad(\omega_n\neq1\text{ 时})$$

几何上很直观:$n$ 个等间隔分布在单位圆上的向量,对称地分布在原点四周,合力(向量和)自然抵消为零。

## 七、为什么单位根重要

单位根之所以在数学和计算机科学里频繁出现,核心原因是:它把"周期性"和"旋转"这两个概念,用一个纯代数的表达式($\omega_n^k$)精确地描述了出来。这使得它成为:

- **离散傅里叶变换(DFT)**的核心:把信号在各个单位根处求值,就是在提取信号里不同"频率"的成分
- **多项式插值与快速乘法(FFT)**的基础:利用单位根的对称性,可以把 $O(n^2)$ 的多项式求值/乘法优化到 $O(n\log n)$
- **循环群论**中的经典例子:$n$ 次单位根在乘法下构成一个循环群,这是抽象代数里研究群结构的入门模型
