# 复数讲解

复数是数系的一次自然扩展,用来解决像 $x^2 = -1$ 这样在实数范围内无解的方程。

## 一、虚数单位

定义一个新的数 $i$,满足:
$$i^2 = -1$$

有了 $i$,就可以表示负数的平方根,比如 $\sqrt{-4} = 2i$。

### 为什么 $x^2=1$ 有解,而 $x^2=-1$ 无解?

对任意实数 $x$(不管是正数、负数还是零),都有:
$$x^2 \geq 0$$

这是实数乘法法则决定的:

- 正数 × 正数 = 正数
- 负数 × 负数 = 正数(负负得正)
- 0 × 0 = 0

所以不存在一个实数,它的平方是负数。

$x^2=1$ 和 $x^2=-1$ 不是"二选一",而是两个独立的方程:

- $x^2 = 1$ 问的是"哪个数的平方等于 **1**?" 答案:$x=1$ 或 $x=-1$(因为 $1^2=1$,$(-1)^2=1$)
- $x^2 = -1$ 问的是"哪个数的平方等于 **-1**?" 在实数范围内,由于平方永远非负,这个方程无解——不是没找到答案,而是根本不存在

换句话说,$x^2=1$ 能解,只是因为 $1$ 恰好是非负数;如果等号右边是任何负数($-1$、$-4$、$-100$ 都一样),在实数里都无解。这两个方程只是恰好右边的数字不同,一个可解一个不可解,并不矛盾。

**那为什么还要"管"$x^2=-1$?**

因为这类方程会在很自然的场合冒出来。比如一元二次方程:
$$x^2 + 1 = 0$$

用求根公式:
$$x = \frac{-b\pm\sqrt{b^2-4c}}{2} = \pm\sqrt{-1}$$

判别式 $b^2-4c=-4$ 是负的,说明"实数世界"里此路不通。历史上数学家们发现:如果假装存在一个数 $i$ 满足 $i^2=-1$,很多计算(尤其是三次方程求根)就能顺利进行,最后得到的答案又变回了合理的实数解。于是它被正式接纳,成为虚数单位。

## 二、复数的代数形式

任意一个复数都可以写成:
$$z = a + bi$$

其中:
- $a$ 叫做**实部**,记作 $\text{Re}(z)$
- $b$ 叫做**虚部**,记作 $\text{Im}(z)$
- 当 $b=0$ 时,$z$ 就是普通实数
- 当 $a=0, b\neq 0$ 时,$z$ 叫纯虚数

## 三、复平面(几何意义)

复数最直观的理解方式,是把它看成平面上的一个点或向量:横轴是实部,纵轴是虚部。这样任何复数运算都有对应的几何图像。

复数 $z = a+bi$ 对应平面上的点 $(a,b)$:

- **模长**(到原点的距离):
$$r = |z| = \sqrt{a^2+b^2}$$
- **幅角**(与实轴正方向的夹角):
$$\theta = \arg(z) = \arctan\left(\frac{b}{a}\right)$$

## 四、三角形式的推导

推导思路是:把点 $(a,b)$ 用"距离 + 角度"重新描述一遍,借助直角三角形里的边角关系。

**第一步:把 $a,b$ 放进直角三角形**

设 $r=|z|$ 是 $(a,b)$ 到原点的距离,$\theta$ 是这条连线与实轴正方向的夹角。把原点、点 $(a,b)$、以及 $(a,b)$ 在实轴上的投影点 $(a,0)$ 连起来,正好构成一个直角三角形:

- 斜边长度是 $r$
- 邻边(沿实轴方向)长度是 $a$
- 对边(沿虚轴方向)长度是 $b$
- 斜边与邻边的夹角就是 $\theta$

**第二步:用三角函数把 $a,b$ 表示成 $r,\theta$**

根据直角三角形里"邻边=斜边×cos"、"对边=斜边×sin"这条最基本的定义:

$$\cos\theta = \frac{a}{r} \quad\Longrightarrow\quad a = r\cos\theta$$

$$\sin\theta = \frac{b}{r} \quad\Longrightarrow\quad b = r\sin\theta$$

**第三步:代回原来的代数式**

$$z = a + bi = r\cos\theta + i \cdot r\sin\theta$$

把公共的 $r$ 提出来,就得到三角形式:

$$z = r(\cos\theta + i\sin\theta)$$

这个公式说的是:**先确定这个点离原点多远($r$),再确定它朝哪个方向($\theta$)**,比起"横坐标 $a$、纵坐标 $b$"这种描述方式,"距离 + 方向"在做乘法、开方、求幂时会方便得多。

再结合欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$,还能写成更简洁的**指数形式**:
$$z = re^{i\theta}$$

## 五、四则运算

**加减法**:直接对实部、虚部分别相加减,几何上等价于向量相加。
$$(a+bi) \pm (c+di) = (a\pm c) + (b\pm d)i$$

**乘法**:按分配律展开,注意 $i^2=-1$:
$$(a+bi)(c+di) = (ac-bd) + (ad+bc)i$$

用指数形式看乘法会更直观:**模长相乘,幅角相加**
$$z_1 z_2 = r_1 r_2\, e^{i(\theta_1+\theta_2)}$$
也就是说,乘一个复数在几何上相当于**缩放 + 旋转**。

**除法**:分子分母同乘"共轭复数"来化简,共轭是把虚部取反:$\bar z = a - bi$
$$\frac{1}{z} = \frac{\bar z}{|z|^2}$$

## 六、为什么复数有用

- 解任意一元二次方程(判别式为负时)
- 电路分析中表示交流电的振幅与相位
- 量子力学的波函数本质上是复数
- 信号处理中的傅里叶变换
- 分形图形(如 Mandelbrot 集)由复数迭代生成
