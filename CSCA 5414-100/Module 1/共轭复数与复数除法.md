# 共轭复数与复数的除法

## 一、什么是共轭复数

对于复数 $z = a+bi$,它的**共轭复数**记作 $\bar z$,定义是把虚部符号反过来:
$$\bar z = a - bi$$

**几何意义**:在复平面上,$\bar z$ 就是 $z$ 关于**实轴**做镜面对称得到的点。

## 二、共轭复数的关键性质

**性质 1:模长不变**

$z$ 和 $\bar z$ 到原点的距离相等,因为翻转虚部不改变距离:
$$|\bar z| = |z|$$

**性质 2:$z \cdot \bar z$ 恒为非负实数**

这是最重要的性质,也是除法能用上共轭的根本原因:
$$z \cdot \bar z = (a+bi)(a-bi) = a^2 - (bi)^2 = a^2 - b^2i^2 = a^2+b^2$$

因为 $i^2=-1$,所以 $-(bi)^2 = -b^2 i^2 = b^2$,两个虚部项刚好抵消,结果变成了一个**纯实数**:
$$z\bar z = a^2+b^2 = |z|^2$$

也就是说:**一个复数乘以它的共轭,虚部必然消失,结果等于它模长的平方**。这个"消虚部"的能力,正是除法要借助共轭的原因。

## 三、复数除法:为什么要乘共轭

除法遇到的麻烦是:分母是复数,不能直接像实数那样"倒过来乘"。比如:
$$\frac{1}{3+4i} = ?$$

分母 $3+4i$ 里带着 $i$,没法直接约分。**解决思路**:分子分母同时乘上分母的共轭,利用"共轭相乘变实数"这个性质,把分母变成纯实数。

**具体步骤**(以 $\dfrac{z_1}{z_2}$ 为例,设 $z_2=c+di$):

$$\frac{z_1}{z_2} = \frac{z_1}{c+di} \times \frac{c-di}{c-di} = \frac{z_1(c-di)}{(c+di)(c-di)} = \frac{z_1(c-di)}{c^2+d^2}$$

分母 $(c+di)(c-di)=c^2+d^2$ 变成了一个普通实数,于是分数就能拆开算了。

**代入具体数字**,算 $\dfrac{1}{3+4i}$:

$$\frac{1}{3+4i} = \frac{1\times(3-4i)}{(3+4i)(3-4i)} = \frac{3-4i}{3^2+4^2} = \frac{3-4i}{25} = \frac{3}{25} - \frac{4}{25}i$$

**再看一个更一般的例子**,算 $\dfrac{2+3i}{1-2i}$:

$$\frac{2+3i}{1-2i} = \frac{(2+3i)(1+2i)}{(1-2i)(1+2i)} = \frac{2+4i+3i+6i^2}{1^2+2^2} = \frac{2+7i-6}{5} = \frac{-4+7i}{5} = -\frac{4}{5}+\frac{7}{5}i$$

注意分子展开时 $6i^2=-6$,这一步容易漏掉符号,要格外小心。

## 四、用倒数公式记忆

上面的过程可以浓缩成一个通用公式,$z$ 的倒数是:
$$\frac{1}{z} = \frac{\bar z}{|z|^2}$$

意思是:**先把 $z$ 换成它的共轭,再除以 $z$ 模长的平方**(这一步是纯实数除法,不再涉及复数除法)。除法 $\dfrac{z_1}{z_2}$ 就等价于 $z_1 \times \dfrac{1}{z_2} = z_1 \times \dfrac{\bar z_2}{|z_2|^2}$。

## 五、小结

| 概念 | 公式 | 作用 |
|---|---|---|
| 共轭 | $\bar z = a-bi$ | 关于实轴镜像 |
| 共轭相乘 | $z\bar z = a^2+b^2 = \lvert z\rvert^2$ | 把复数变成实数,是除法的关键 |
| 除法 | $\dfrac{z_1}{z_2}=\dfrac{z_1\bar z_2}{\lvert z_2\rvert^2}$ | 分子分母同乘分母共轭,消去分母的虚部 |

## 六、共轭在求根公式中的应用

回顾一元二次方程 $ax^2+bx+c=0$($a,b,c$ 为实数)的求根公式:
$$x = \frac{-b\pm\sqrt{b^2-4ac}}{2a}$$

当判别式 $\Delta = b^2-4ac < 0$ 时,$\sqrt{\Delta}$ 是虚数。设 $\Delta = -k$($k>0$),则 $\sqrt{\Delta} = i\sqrt{k}$,两个根变成:

$$x_1 = \frac{-b}{2a} + \frac{\sqrt{k}}{2a}i, \qquad x_2 = \frac{-b}{2a} - \frac{\sqrt{k}}{2a}i$$

观察这两个根:实部完全相同,虚部符号相反——**$x_2$ 正是 $x_1$ 的共轭复数**,即 $x_2=\overline{x_1}$。这不是巧合,而是求根公式里 $\pm\sqrt{\Delta}$ 这个"$\pm$"结构决定的:两个根除了虚部的符号,其他部分完全一致。

## 七、实系数多项式的虚根成对定理

上面二次方程的现象可以推广到任意次数的多项式,这就是**共轭根定理**:

> 如果一个多项式 $P(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ 的所有系数 $a_n,\ldots,a_0$ 都是**实数**,并且 $z=p+qi$($q\neq0$)是它的一个根,那么 $\bar z = p-qi$ 也一定是它的根。

### 证明思路

关键工具是:**取共轭这个操作,可以"穿透"实系数多项式的加法和乘法**。

**第一步**:共轭运算对加法、乘法有以下性质(可以直接从定义验证):
$$\overline{u+v} = \bar u+\bar v, \qquad \overline{u\times v} = \bar u\times\bar v$$

**第二步**:如果系数 $a_k$ 是实数,那么 $\overline{a_k}=a_k$(实数的共轭就是它自己)。

**第三步**:已知 $z$ 是根,即 $P(z)=0$。两边同时取共轭:
$$\overline{P(z)} = \overline{a_nz^n+\cdots+a_1z+a_0} = \bar 0 = 0$$

利用第一步的性质,把共轭符号一层层拆到每一项内部:
$$\overline{a_nz^n}+\cdots+\overline{a_1z}+\overline{a_0} = \overline{a_n}\,\overline{z}^{\,n}+\cdots+\overline{a_1}\,\overline z+\overline{a_0} = 0$$

再用第二步(系数是实数,取共轭不变):
$$a_n\bar z^{\,n}+\cdots+a_1\bar z+a_0 = 0$$

这正好就是 $P(\bar z)=0$——也就是说 $\bar z$ 也满足这个多项式方程,所以 $\bar z$ 也是根。

### 直观理解

这条定理成立的根本原因是:**多项式的系数是实数,意味着方程本身在"取共轭"这个操作下是对称的**。如果方程有一个不在实轴上的根,那么它的镜像(共轭)也必然满足同一个方程——因为方程"看不出"z 和 z̄ 的区别,系数是实数保证了这种对称性不会被破坏。

### 实际意义

- **虚根总是成对出现**:一个实系数多项式,如果有虚根,数量一定是偶数个(每对共轭算两个)
- **奇数次实系数多项式至少有一个实根**:比如三次方程,3个根里如果有虚根就必然成对(占2个),剩下1个只能是实根
- **因式分解时可以配对成实系数二次因子**:一对共轭根 $p\pm qi$ 对应的两个一次因子相乘,结果系数必为实数:
$$(x-(p+qi))(x-(p-qi)) = (x-p)^2+q^2 = x^2-2px+(p^2+q^2)$$
这说明任何实系数多项式都可以分解成实系数的一次因子和二次因子的乘积——这也是多项式因式分解理论里的一个基本结论。
