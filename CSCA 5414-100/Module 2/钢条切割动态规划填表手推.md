# 钢条切割问题:动态规划填表手推($L=10$)

价格表:切3米赚 \$1.80,切4米赚 \$2.00。

## 一、$i$ 的含义

$T[i]$ 表示的是:**如果手上有一根长度为 $i$ 米的钢条,把它切割到最优,能获得的最大收入是多少**。

$i$ 从 $0$ 递增到 $L=10$,依次代表"长度为0的钢条""长度为1的钢条"……一直到"长度为10的钢条(即原始问题本身)"。填表顺序是按"钢条越来越长"来的,不是"切了多少米"。

$S[i]$ 记录的是:面对一根长度为 $i$ 的钢条,当前这一步"第一刀"应该切多长,才能通向全局最优解。

## 二、递推公式

$$T[i] = \max\Big(0,\ \underbrace{T[i-3]+1.8}_{\text{切3米}},\ \underbrace{T[i-4]+2.0}_{\text{切4米}}\Big)$$

如果 $i-3<0$ 或 $i-4<0$,对应那一项直接跳过,不参与比较,相当于该决策不可行。

## 三、逐行手推

**$i=0$**:钢条长度为0,没有任何决策可做。
$$T[0]=0,\quad S[0]=\text{无}$$

**$i=1$**:$i-3=-2<0$,$i-4=-3<0$,两个切法都不可行,只剩"浪费"这一个选项。
$$T[1]=\max(0)=0,\quad S[1]=\text{浪费}$$

**$i=2$**:同样两个切法都不可行($2-3=-1<0$,$2-4=-2<0$)。
$$T[2]=\max(0)=0,\quad S[2]=\text{浪费}$$

**$i=3$**:切3米可行($3-3=0\geq0$),切4米不可行($3-4=-1<0$)。
$$T[3]=\max\big(0,\ T[0]+1.8\big)=\max(0,\ 0+1.8)=1.8,\quad S[3]=\text{切3米}$$

**$i=4$**:两个切法都可行了。
$$T[4]=\max\big(0,\ \underbrace{T[1]+1.8}_{0+1.8=1.8},\ \underbrace{T[0]+2.0}_{0+2.0=2.0}\big)=2.0,\quad S[4]=\text{切4米}$$

**$i=5$**:
$$T[5]=\max\big(0,\ \underbrace{T[2]+1.8}_{0+1.8=1.8},\ \underbrace{T[1]+2.0}_{0+2.0=2.0}\big)=2.0,\quad S[5]=\text{切4米(剩1)}$$

**$i=6$**:
$$T[6]=\max\big(0,\ \underbrace{T[3]+1.8}_{1.8+1.8=3.6},\ \underbrace{T[2]+2.0}_{0+2.0=2.0}\big)=3.6,\quad S[6]=\text{切3米}$$

**$i=7$**:
$$T[7]=\max\big(0,\ \underbrace{T[4]+1.8}_{2.0+1.8=3.8},\ \underbrace{T[3]+2.0}_{1.8+2.0=3.8}\big)=3.8$$
这里出现了**平局**:切3米和切4米都能得到 \$3.80。任选一个记录即可,这里记为 $S[7]=\text{切3米}$。

**$i=8$**:
$$T[8]=\max\big(0,\ \underbrace{T[5]+1.8}_{2.0+1.8=3.8},\ \underbrace{T[4]+2.0}_{2.0+2.0=4.0}\big)=4.0,\quad S[8]=\text{切4米}$$

**$i=9$**:
$$T[9]=\max\big(0,\ \underbrace{T[6]+1.8}_{3.6+1.8=5.4},\ \underbrace{T[5]+2.0}_{2.0+2.0=4.0}\big)=5.4,\quad S[9]=\text{切3米}$$

**$i=10$**:
$$T[10]=\max\big(0,\ \underbrace{T[7]+1.8}_{3.8+1.8=5.6},\ \underbrace{T[6]+2.0}_{3.6+2.0=5.6}\big)=5.6$$
又是一个**平局**(两种切法都能凑出 \$5.60)。这里记录 $S[10]=\text{切4米}$。

## 四、完整表格

| $i$ | $T[i]$ | $S[i]$(最优决策) |
|---|---|---|
| 0 | 0 | 无 |
| 1 | 0 | 浪费 |
| 2 | 0 | 浪费 |
| 3 | 1.8 | 切3米 |
| 4 | 2.0 | 切4米 |
| 5 | 2.0 | 切4米(剩1) |
| 6 | 3.6 | 切3米 |
| 7 | 3.8 | 切3米(平局) |
| 8 | 4.0 | 切4米 |
| 9 | 5.4 | 切3米 |
| 10 | 5.6 | 切4米(平局) |

## 五、用 $S$ 表回溯出完整切法(验证)

从 $S[10]=$"切4米"开始:
$$10\xrightarrow{\text{切4米}}6\xrightarrow{S[6]=\text{切3米}}3\xrightarrow{S[3]=\text{切3米}}0\ (\text{结束})$$

回溯出的完整方案是:**4米 + 3米 + 3米**,总收入 $2.0+1.8+1.8=5.6$——和 $T[10]=5.6$ 完全吻合,验证正确。
